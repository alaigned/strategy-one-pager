# Contributing

This repository is generated from Alaigned's development repository. Every release overwrites the
files here, so a pull request against them cannot be merged. What helps:

- **A report from a real run.** Which tool, which model, what you attached (shape, not content),
  what came out, what you expected instead. Use the issue form; it asks for exactly that.
- **A strategy shape the skill handles badly.** OKR sheets, board decks, founder notes, multi-entity
  groups. Describe the shape; do not send confidential material.
- **Wording in the methodology references** that reads wrong in your language (English, Czech,
  Slovak).

Open an [issue](https://github.com/alaigned/strategy-one-pager/issues/new/choose) for bugs and
failed runs, a [discussion](https://github.com/alaigned/strategy-one-pager/discussions) for
questions and for showing what you built. Email **support@alaigned.com** if neither fits.
