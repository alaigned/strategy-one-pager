# Security

The skill runs inside your AI tool's session. Its two scripts are standard-library Python, make no
network calls, and write only the files they name in their output. The one outward action the skill
can take is a public-data search about the company being analyzed, and it asks for your consent
first. No Alaigned server is contacted and nothing you attach leaves your environment.

To report a security concern, email **support@alaigned.com** with "security" in the subject.
Please do not open a public issue for it.
